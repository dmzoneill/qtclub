# Qt Club Client Database

A PHP and MySQL web application for managing the members of a club.

## What it does

- Add, edit, search, view and print members.
- Track direct debits, member history and statistics, with graphs.
- Send email to clients, manage a mailing list and send SMS messages through an
  SMS API.
- A calendar, a live clock and user administration.

## Tech

- PHP and MySQL
- A bundled rich text editor
- JavaScript and CSS

## Setup

Create the database from `sql.txt`, set the connection details in `connect.php`,
and serve the folder with PHP.
